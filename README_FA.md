# پروژه نرم‌افزار ماشینری

این بسته، **پروژه اولیه قابل ساخت با Flutter** برای شروع اپ اندرویدی «ماشینری» است؛ APK آماده نیست.

## امکانات موجود در نمونه اولیه
- داشبورد ساده
- ثبت گزارش تعمیرات
- فهرست گزارش‌ها
- ثبت نام پرسنل و امتیاز کارانه هر نفر برای هر گزارش
- تعریف امتیاز پایه نوع کار
- تأیید نهایی گزارش و امتیاز فقط توسط مدیر
- ذخیره محلی اطلاعات روی گوشی
- بدون بخش اضافه‌کاری
- بدون محاسبه یا نمایش مبلغ ریالی/تومانی

## ساخت APK با GitHub
1. فایل ZIP را از حالت فشرده خارج کنید و همه فایل‌ها را در یک مخزن GitHub بارگذاری کنید.
2. به زبانه **Actions** بروید.
3. گردش‌کار **Build Android APK** را اجرا کنید.
4. پس از پایان موفق، در بخش **Artifacts** فایل `mashinari-debug-apk` را دانلود کنید.
5. فایل ZIP مربوط به Artifact را باز کنید تا `app-debug.apk` را ببینید و روی گوشی نصب کنید.

## نکات مهم
- این نسخه، نمونه اولیه است و اطلاعات را روی همان گوشی ذخیره می‌کند؛ هنوز همگام‌سازی آنلاین چندکاربره، ورود امن کاربران، عکس/فیلم، خروجی PDF/Excel و قابلیت آفلاینِ همراه با همگام‌سازی ابری پیاده‌سازی نشده‌اند.
- برای استفاده سازمانی واقعی، باید احراز هویت، سطح دسترسی، پشتیبان‌گیری و همگام‌سازی سمت سرور اضافه و آزمایش شوند.
- اگر GitHub هنگام اجرا گزینه پرداخت یا محدودیت نشان داد، چیزی خریداری نکنید؛ ابتدا خطای دقیق را بررسی کنید.
